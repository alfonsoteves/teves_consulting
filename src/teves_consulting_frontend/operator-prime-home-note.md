# Operator Prime Home Note

Phase 9.7 recalibrates `operator.html` around Prime Home.

Prime Home is the first Internal Aion operating environment surface. It restores current project state, priorities, approved packets, pending decisions, and recommended next actions through the protected Render bridge.

The public frontend remains frontend-only. It does not expose Teves backend internals, provider credentials, private continuity, tests, or operator scripts.

Prime Home does not:

- execute actions;
- silently invoke Mirror or Engineer;
- write memory;
- mutate provider routes;
- change public behavior;
- claim frontier model superiority.
