# Operator Prime Trial Capture Note

Phase 9.11B adds a frontend-only Prime trial capture workspace to `operator.html`.

The workspace lets the signed-in operator enter:

- Trial A normal ChatGPT execution evidence;
- context restoration effort;
- clarifying exchanges;
- usefulness assessment;
- cognitive load assessment;
- latency and token/cost evidence where available;
- operator assessment answers.

The generated review packet is local/browser-only.

The workspace does not submit to the backend, write canonical memory, accept Prime, start Mirror, approve Oracle, or expose backend internals.
