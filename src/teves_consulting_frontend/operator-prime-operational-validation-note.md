# Operator Prime Operational Validation Note

Phase 9.11B adds a frontend-only Prime operational validation criteria preview to `operator.html`.

The preview defines the baseline comparison before any Prime operational validation run is treated as intelligence evidence:

- Baseline A: normal ChatGPT workflow without Aion-owned continuity;
- Baseline B: Internal Aion Prime with Aion continuity and governed context.

The public frontend shows:

- source 9.11A acceptance state;
- baseline comparison;
- required measures;
- execution evidence requirements;
- operator assessment questions;
- criteria-only boundary evidence.

The preview does not execute validation, call providers, select routes, write memory, approve Oracle, or expose backend internals.
